Eddy Office

Eddy Sheet for Excel files and Eddy Doc for Word files. Everything runs in your browser; your files never leave your computer.

Eddy SheetOpen, edit, print and save .xlsx and .csv files
Eddy DocOpen, edit, print and save .docx files

Install on your laptop (Chrome or Edge)

  1. Open Eddy Sheet above. Click the install icon at the right end of the address bar (a small screen with an arrow), or open the browser menu and choose Install Eddy Sheet (in Edge: Apps → Install this site as an app).
  2. Do the same for Eddy Doc.
  3. Both now have their own window and an icon in the Start menu, and they work without internet.

Open files from your computer

  1. Right-click an .xlsx file → Open with → Eddy Sheet. For a .docx file choose Eddy Doc.
  2. To make it the default for double-clicking, choose Choose another app, pick Eddy Sheet or Eddy Doc and tick Always use this app.
  3. The first time, the browser asks whether the app may open that kind of file. Choose Allow.
  4. Click Save to write your changes back into the same file. The first save asks once for permission to change the file. Save a copy downloads a separate copy instead.

If a file is also open in Excel or Word, Windows locks it; Eddy then saves a copy to your downloads folder instead.
